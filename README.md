This project was created as part of the Frontend Wizard Stage 1 task.
It’s a simple multi-page frontend website consisting of:

A Profile Card page (index.html)

An About Me page

A Contact Us page with form validation


The goal is to demonstrate semantic HTML, accessibility, responsive design, and functional form validation.




# Pages and Features

 Profile Page (index.html)

Displays a clean personal profile card.

Shows developer info, hobbies, dislikes, and social links.

Uses accessible and semantic structure.

Navigation bar links to all pages.


# About Page (about.html)

Includes reflective sections:

Bio

Goals in the program

Areas of low confidence

Note to future self

Extra thoughts


Fully semantic and accessible layout.

Organized with <main> and <section> tags.


# Contact Us Page (contact.html)

Contains a form with the following fields:

Full name

Email

Subject

Message


Includes form validation:

All fields are required.

Valid email format (name@example.com).

Message must be at least 10 characters.


Displays success and error messages with correct data-testids.

Fully keyboard accessible and responsive.





# Accessibility & Responsiveness

All inputs are associated with labels.

ARIA attributes used for error messages.

Responsive on mobile, tablet, and desktop.

Navigation is fully keyboard-friendly.
